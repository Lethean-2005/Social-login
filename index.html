Onboarding Guide

Project Setup & Local Installation

Follow this official walkthrough to get your local environment ready and the project running smoothly.

1

Clone the Repository

Open your terminal and clone the project source code to your machine:

git clone https://github.com/your-org/project-name.git
2

Configure Environment Variables

Duplicate the example configuration file and update it with your local settings:

cd project-name
cp .env.example .env
3

Install Dependencies & Run

Install required packages and boot up the development server:

npm install
npm run dev
